Student Performance Tracker (Excel)

Universities often keep marks in scattered files, calculate GPAs by hand, and notice struggling students too late. This workbook turns raw marks into grades, GPAs, rankings and insights in one place.

Features
- Student and course registers with dropdowns and duplicate-ID checks
- Marks entry with automatic totals, grades, grade points and pass/fail
- Semester and cumulative GPA, class rankings and degree classification
- Standing flags: Dean's List, At risk and Probation
- Printable one-page academic transcript for any student
- Interactive dashboard filtered by programme and semester, with KPIs, grade distribution, course performance and top and lowest performers
- Course analysis that flags high failure rates
- Editable grading scale, pass mark and thresholds

Tools: Microsoft Excel (formulas, data validation, conditional formatting, charts)

Note: All student data is fictional. The grading scale is a typical 5-point scale, so adjust it on the Settings sheet to match your university.
